Description
===========

Allow to set point-of-sale orders as to-invoice by default.


Usecase
=======




Installation
============




Configuration
=============

This module adds an “Invoice By Default” option to the Accounting
section of the Point of Sale settings.

To set orders as to-invoice by default, check the “Invoice By Default”
checkbox.
